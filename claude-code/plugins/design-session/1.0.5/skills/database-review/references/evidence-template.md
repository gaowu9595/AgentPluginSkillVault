# 数据库审核证据包模板

机器标识：`template-kind: database-review-evidence-v3`、`quick-no-full-evidence`。

> 仅供 delta/full 使用。quick 不生成完整证据包。

## 0. 审核路由与成本

| 项目 | 内容 |
|---|---|
| review mode | delta/full |
| baseline | object/complete/none + 摘要 |
| changed tables/fields/constraints/invariants | N/N/N/N |
| files to read | N + 白名单 |
| agents | 0/1/2 + 选择理由 |
| implementation plan | none |
| auto repair round | 0/1 |

## 1. 基线链与变更清单

| 项目 | 路径或摘要 | 是否可继承 |
|---|---|---|
| 设计 | | |
| 代码 | | |
| 证据 | | |
| 旧发现与裁决 | | |

| 变更 ID | 基线位置 | 当前位置 | 变化类型 | 受影响对象 | 受影响不变量/写入路径 |
|---|---|---|---|---|---|

## 2. 需求与代码事实

| 编号 | 类型 | 事实 | 来源与精确位置 | 适用范围 |
|---|---|---|---|---|

类型只能是：`REQ-FACT / CODE-FACT / DECISION / ASSUMPTION`。未找到时记录已检查范围，不得猜测。

## 3. 最小化证据矩阵

### 3.1 逐表

| 表 | 一行含义 | 已检索现有对象 | 写入/读取方 | 生命周期 | 删除后具体失败 | 更小方案为何不成立 | 候选结论 |
|---|---|---|---|---|---|---|---|

### 3.2 逐字段

| 表.字段 | 权威/派生/快照/元数据 | 已有来源 | 独立读取价值 | 能否计算或关联 | 删除后具体失败 | 候选结论 |
|---|---|---|---|---|---|---|

先完成本节。未通过的候选对象不进入后续完整性矩阵。

## 4. 关系与生命周期

|---|---|---|---|---|---|---|
